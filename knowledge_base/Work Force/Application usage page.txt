Page Name
Application Usage Timeline

Module Name
Work Stream

Overview
The Application Usage Timeline page provides a second-by-second visualization of an employee's application usage for a selected working day. It displays every application session performed by the employee in chronological order, allowing managers and leadership to understand exactly which applications were used, when they were used, and for how long during the selected date.
Users first select an employee from the available employee list generated by the Daily Flow page. After selecting an employee and submitting the request, the system retrieves the complete application activity history for the selected day and displays it as a horizontal timeline. Each activity segment represents an application usage session, showing the application's start time, end time, duration, usage category, and associated website information where applicable.
The timeline categorizes application usage into Productive Applications, Unproductive Applications, and General Application Usage, using different colors to distinguish each activity type. Users can hover over individual activity segments to view detailed information such as the application name, website name, usage type, and exact usage duration.
The Application Usage Timeline page is primarily used by managers, leadership, HR, and administrators to analyze employee application usage, understand work behavior, monitor software utilization, investigate productivity patterns, and review detailed application activity throughout the selected working day.

Purpose
The primary purpose of the Application Usage Timeline page is to provide a detailed view of an employee's application usage throughout a selected working day. It enables organizations to understand how employees utilize business applications during working hours by presenting every application session in chronological order.
The page helps managers analyze application usage behavior, monitor productive and unproductive application usage, review software utilization, investigate employee activity during specific time periods, and gain detailed operational insights into daily work patterns. By visualizing every application session, the page supports productivity analysis, operational monitoring, and workforce activity auditing.



Features
* Displays a second-by-second timeline of employee application usage for the selected working day. 
* Allows users to select an employee from the available employee list to generate the application usage timeline. 
* Provides Submit functionality to retrieve the selected employee's application activity. 
* Provides Reset functionality to clear the selected employee and reset the timeline. 
* Supports exporting the application usage report as a CSV file for reporting and offline analysis. 
* Displays every application usage session in chronological order throughout the selected working day. 
* Shows the start time and end time for every application usage session. 
* Displays the duration of each application session based on the recorded activity. 
* Displays the application name associated with each activity segment. 
* Displays the corresponding website name when website information is available. 
* Categorizes application usage into: 
o Productive Applications 
o Unproductive Applications 
o General Application Usage 
* Uses color-coded timeline segments to visually distinguish different application usage categories. 
* Provides interactive tooltips displaying: 
o Application Name 
o Website Name 
o Usage Type 
o Start Time 
o End Time 
o Duration of Usage 
* Retrieves application usage records dynamically for the selected employee and selected working date. 
* Displays loading indicators, validation messages, and notifications while application usage data is being retrieved or exported.
